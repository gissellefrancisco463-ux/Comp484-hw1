# HW2 Structuring Page Content

This assignment focuses on creating a consistent and semantic structure across all HTML pages. Including structure.html to understand how structural elements such as <header>, <nav>, <main>, <article>, <section>, <aside>, and <footer> are organized and how ARIA roles are used. I will then create a diagram and document outline of the page structure. Using this structure as a guide, I will updated the remaining HTML pages so they follow the same logical layout and apply appropriate ARIA roles for accessibility.
